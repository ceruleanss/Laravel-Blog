Functional Requirements Document (FRD)1. Project OverviewProject Name: Modern Laravel 13 Blog SystemObjective: Build a responsive, component-driven multi-user blog platform allowing readers to browse/filter articles and authenticated authors to manage their own posts via a dedicated dashboard.Target Architecture: Monolithic MVC architecture using Laravel 13, SQLite, Blade Components, Tailwind CSS, and Alpine.js.2. Technical Stack & ConstraintsBackend: PHP 8.2+, Laravel 13.xDatabase: SQLite (database/database.sqlite)Authentication: Laravel Breeze (Blade with Alpine.js stack)Frontend Styling & Interactivity: Tailwind CSS, Alpine.js, Flowbite (optional UI patterns)Templating Strategy: Strict use of Anonymous & Class-based Blade Components (<x-layout>, <x-navbar>, <x-post-card>)—no traditional @extends or @section layout inheritance.3. Data Models & Relationships (ERD)EntityKey AttributesRelationshipsUserid, name, username (unique), email, password, avatar (nullable), timestampshasMany(Post::class)Categoryid, name, slug (unique), color (Tailwind badge color), timestampshasMany(Post::class)Postid, title, slug (unique), author_id (FK to users), category_id (FK to categories), body (text), image (nullable), published_at, timestampsbelongsTo(User::class, 'author_id'), belongsTo(Category::class)4. Functional RequirementsFR-01: Authentication & User Profile (Laravel Breeze)FR-01.1: Users can register with Name, Username, Email, and Password.FR-01.2: Users can log in, log out, and reset passwords.FR-01.3: Authenticated users can update their profile details, password, and upload an avatar image.FR-02: Public Blog Feed & DiscoveryFR-02.1: Visitors can view a paginated list of published blog posts (latest first).FR-02.2: Each post card displays the category badge (with dynamic color), title, excerpt, author name/avatar, relative publish time (diffForHumans()), and link to read more.FR-02.3: Visitors can filter posts by:Search Keyword (matches post title or body).Category (?category=slug).Author (?author=username).Combined Filters (e.g., searching within a specific category or author using Eloquent Local Scopes scopeFilter).FR-02.4: Eager loading (with(['author', 'category'])) must be enforced on queries to prevent $N+1$ query performance issues.FR-03: Single Post ViewFR-03.1: Visitors can view a full post via clean route-model binding (/posts/{post:slug}).FR-03.2: Displays full post content, featured image (if uploaded), author metadata, and category link.FR-04: Author Dashboard (CRUD Operations)FR-04.1: Authenticated users have access to /dashboard listing only their own posts in a responsive table.FR-04.2: Create Post: Form with validation for Title, Slug (auto-generated via Alpine.js/JS from title), Category selector, optional Featured Image upload, and Body content.FR-04.3: Read/Preview: Authors can preview their individual posts from the dashboard.FR-04.4: Update Post: Authors can edit their existing posts (replacing old uploaded images in storage if a new one is uploaded).FR-04.5: Delete Post: Authors can delete their posts with an Alpine.js confirmation modal; associated image files are deleted from storage.FR-04.6: Authorization Policy: Users cannot edit or delete posts belonging to other users (enforced via Laravel PostPolicy or Gate).FR-05: UI & Component ArchitectureFR-05.1: All views must use Blade components (<x-app-layout>, <x-public-layout>, <x-nav-link>, <x-badge>).FR-05.2: Interactive elements (mobile hamburger menu, user profile dropdown, delete confirmation modal, flash notification dismissal, slug auto-generation) must be powered by Alpine.js.
